### Week 3 Objectives:

* Understand the architecture of Amazon Virtual Private Cloud (Amazon VPC).
* Design and deploy a private network infrastructure on AWS.
* Apply security mechanisms to control network traffic between AWS resources.

### Tasks to Be Carried Out This Week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 2 | - Study the architecture of Amazon VPC.<br>- Learn about CIDR blocks, Public Subnets, Private Subnets, and Route Tables.<br>- Analyze common network architectures used in AWS environments. | 05/04/2026 | 05/04/2026 | https://docs.aws.amazon.com/vpc/ <br> https://000003.awsstudygroup.com/ |
| 3 | - Design and create an Amazon Virtual Private Cloud (VPC).<br>- Configure Public and Private Subnets.<br>- Set up Route Tables and an Internet Gateway to provide Internet access for the Public Subnet. | 05/05/2026 | 05/05/2026 | https://docs.aws.amazon.com/vpc/ |

### Week 3 Achievements:

* Understood the role of Amazon VPC in building secure AWS network infrastructures.
* Successfully designed and deployed a Virtual Private Cloud with both Public and Private Subnets.
* Configured Internet Gateways and Route Tables to manage network traffic effectively.
* Understood the differences between Security Groups and Network ACLs and applied them appropriately.
* Successfully verified network connectivity between AWS resources based on the configured security rules.
* Acquired the ability to build a basic AWS network architecture that satisfies both connectivity and security requirements.
