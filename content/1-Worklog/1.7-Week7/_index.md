### Week 7 Objectives:

* Understand the concept of containers and the benefits of Docker in application development.
* Package an application using Docker Images and manage it with Docker Containers.
* Deploy containerized applications on Amazon ECS.

### Week 7 Achievements:

* Understood the Docker architecture and the application containerization workflow.
* Successfully built Docker images and deployed applications using Docker containers.
* Understood the structure of Amazon ECS, including Clusters, Task Definitions, Tasks, and Services.
