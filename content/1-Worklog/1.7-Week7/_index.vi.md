### Mục tiêu tuần 7:

* Hiểu khái niệm Container và lợi ích của Docker trong phát triển ứng dụng.
* Đóng gói ứng dụng bằng Docker Image và quản lý bằng Docker Container.
* Triển khai ứng dụng trên Amazon ECS để quản lý container trên AWS.

### Kết quả đạt được tuần 7:

* Hiểu nguyên lý hoạt động của Docker và quy trình container hóa ứng dụng.
* Xây dựng thành công Docker Image và triển khai ứng dụng bằng Docker Container.
* Hiểu cấu trúc của Amazon ECS gồm Cluster, Task Definition, Task và Service.
* Đẩy Docker Image lên Amazon Elastic Container Registry (Amazon ECR) thành công.
* Triển khai ứng dụng container trên Amazon ECS và xác minh ứng dụng hoạt động ổn định.
* Có khả năng áp dụng Docker và Amazon ECS để triển khai ứng dụng theo mô hình container trên AWS.
