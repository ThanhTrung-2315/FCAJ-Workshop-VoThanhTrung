### Week 2 Objectives:

* Understand how to deploy and manage virtual servers using Amazon EC2.
* Work with Amazon S3 for object storage.
* Deploy and connect to a relational database using Amazon RDS.

### Week 2 Achievements:

* Understood the process of launching and configuring an Amazon EC2 instance.
* Learned how to select an appropriate Amazon Machine Image (AMI), Instance Type, Storage, and Security Group.
* Successfully established an SSH connection to an EC2 instance.
* Used Amazon S3 to store, organize, and retrieve objects.
* Successfully deployed an Amazon RDS database instance and verified database connectivity.
* Acquired the ability to integrate Amazon EC2, Amazon S3, and Amazon RDS into a basic AWS application architecture.
