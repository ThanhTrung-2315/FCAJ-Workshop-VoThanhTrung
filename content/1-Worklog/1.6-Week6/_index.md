### Week 6 Objectives:

* Understand the concept of Infrastructure as Code (IaC) on AWS.
* Use AWS CloudFormation to automate infrastructure deployment.
* Manage and update AWS resources through CloudFormation Stacks.

### Week 6 Achievements:

* Understood the principles of Infrastructure as Code (IaC) and the role of AWS CloudFormation in infrastructure automation.
* Successfully created CloudFormation templates using the YAML format.
* Deployed AWS resources automatically through CloudFormation Stacks.
* Updated and managed infrastructure using CloudFormation instead of manual configuration through the AWS Management Console.
* Learned how to monitor stack status, review stack events, and troubleshoot deployment failures.
* Gained the ability to reuse CloudFormation templates for consistent and efficient infrastructure deployment across AWS environments.
